# Contributing to Form Digital

Issues and pull requests are welcome. Describe the form or workflow that needs work, the result you expected, and what happened instead. Use sample files you made yourself; do not post customer forms, completed records, credentials, or local data folders.

For code changes, install the pinned pnpm version listed in `package.json`, then run `pnpm install --frozen-lockfile`, `pnpm check`, and `pnpm test`. Add a focused browser test when the change affects a user workflow. Keep new interface text available in Traditional Chinese, Simplified Chinese, and English.
