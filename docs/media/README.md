## Capture recipe

1. Start the packaged local app with a new data folder, separate configuration and unused ports. Complete onboarding and select English.
2. Prepare a one-page fictional purchase request. The MCP design tools were used to prepare this source; import its PDF through the app with automatic field suggestions disabled.
3. Review the imported page. Add a text field, name it Requested by, drag and resize it over the printed box, confirm and save. These are the four import GIF frames.
4. Prepare the remaining date, department, priority, equipment, table and reason fields using the app's MCP tools. Review them before publishing. This setup is not included in the short import GIF.
5. For the filled example, use circle marks for both single and multiple choices. Set table column D to B*C for each of three rows, with two decimal places.
6. In the browser, create a record and enter Jamie Chan, 2026-10-27, Design team, Standard priority, Monitor and Dock. Enter the rows below, save and export PDF with original form.
7. Render the exported PDF and compare its answers, marks and calculated values with the saved record. Open the first-connection MCP guide for the tutorial screenshot, keeping credentials out of frame.
